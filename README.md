Responsi Fullstack – Dashboard Manajemen Tugas

## 📌 Deskripsi Project

Project ini merupakan aplikasi Dashboard Manajemen Tugas yang dibuat untuk memenuhi tugas Responsi Fullstack.

Aplikasi ini digunakan untuk membantu pengguna mengelola daftar tugas dengan menginput nama, deskripsi tugas, prioritas, dan status pengerjaan.

Aplikasi dikembangkan menggunakan React JS dan Bootstrap dengan tampilan dashboard yang sederhana dan mudah digunakan.

## 🚀 Fitur Aplikasi

- *Dashboard:* Menampilkan halaman utama aplikasi.
- *Tambah Tugas:* Menambahkan tugas baru.
- *Edit Tugas:* Mengubah informasi tugas yang sudah dibuat.
- *Hapus Tugas:* Menghapus tugas dari daftar.
- *Pencarian Tugas:* Mencari tugas berdasarkan nama atau deskripsi.
- *Prioritas Tugas:* Menentukan tingkat prioritas Low, Medium, atau High.
- *Status Tugas:* Menentukan status pengerjaan seperti To Do.

## ⚙️ Cara Menjalankan Aplikasi

### 1. Clone Repository

bash
git clone https://github.com/Ananda2006-ops/responsi-fullstack-nanda.git


### 2. Masuk ke Folder Project

bash
cd responsi-fullstack-nanda


### 3. Install Dependencies

bash
npm install


### 4. Jalankan Aplikasi

bash
npm run dev


### 5. Buka Aplikasi

Buka alamat lokal yang muncul di terminal, biasanya:

text
http://localhost:5173


## 📖 Cara Penggunaan

1. Buka aplikasi Dashboard Manajemen Tugas.
2. Masukkan nama pengguna atau nama tugas sesuai kolom yang tersedia.
3. Isi deskripsi tugas.
4. Tentukan prioritas tugas.
5. Pilih status pengerjaan.
6. Klik tombol tambah untuk menyimpan tugas.
7. Gunakan tombol edit untuk mengubah tugas.
8. Gunakan tombol hapus untuk menghapus tugas.
9. Gunakan fitur pencarian untuk menemukan tugas.

## 🎯 Tujuan Project

Tujuan pembuatan aplikasi ini adalah untuk menerapkan konsep pengembangan aplikasi frontend menggunakan React JS, memahami penggunaan komponen, pengelolaan state, serta penerapan Bootstrap dalam membangun tampilan website yang responsif.
